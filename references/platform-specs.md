# 发布层：平台规格、画幅适配与发布检查

> 成片出来只是完成了一半。同一份素材发错比例、被 UI 挡住字幕、封面裁掉人像，前面的功夫全白费。
> **原则一句话：一次制作主版本，按平台导出适配版。** 主版本 = 9:16 竖屏。

---

## 一、尺寸速查（快照日期 2026-10）

| 平台 | 主比例 | 推荐分辨率 | 时长上限（常见口径） | 封面 | 其它 |
|---|---|---|---|---|---|
| 抖音 | 9:16 | 1080×1920（最高 4K） | ~15 分钟 | 1080×1920，自动截帧或手动选帧 | 文件上限约 4GB；支持 HDR10+ |
| 快手 | 9:16 | 1080×1920 | ~10 分钟 | 1080×1920，自动截帧 | 与抖音接近 |
| 微信视频号 | 9:16 | 1080×1920；横屏特殊 **1080×1260（≈5:6）**；方形 1080×1080 | 30–60 分钟 | 随视频，自动截帧 | 文件上限约 2GB；**压缩较狠**，码率给足 |
| 小红书 | 9:16 或 **3:4** | 1080×1920 / **1080×1440（3:4）** | 1–5 分钟（口径不一，**按 ≤1 分钟做最稳**） | **1080×1440（3:4）** ≤5MB | 3:4 在双列瀑布流里**显示面积更大，更易点击** |
| B 站 | **16:9**（主） | 1920×1080 / 3840×2160 | 无硬上限，建议 ≤30 分钟 | **1146×717 或 1920×1200（16:10）** ≤2MB | 封面比例与视频不同，**必须单独做** |

> ⚠️ 平台规则变化频繁，上表为 **2026-10 快照**，且部分口径在不同来源间不一致。**发布前以平台创作者后台的当前要求为准。**

---

## 二、画幅决策：什么时候不该用 9:16

9:16 是覆盖面最广的主版本，但不是唯一正确答案：

| 内容类型 | 建议画幅 | 理由 |
|---|---|---|
| 带货、口播、教程、Vlog、产品展示 | **9:16** | 手机竖持是默认姿势，完播率更高 |
| 小红书图文/视频笔记 | **3:4** | 双列瀑布流里 3:4 的展示面积大于 9:16 |
| 电影感短片、风景、多人访谈 | **16:9**（B 站主战场） | 横向信息量更大，电影感靠横向构图 |
| 品牌形象片（官网/电视/发布会） | **16:9** 或 2.39:1 | 大屏播放，不是信息流场景 |

---

## 三、⚠️ 电影画幅 vs 竖屏：一对硬冲突（必读）

`shiyiagi-director-film` 与 `shiyiagi-director-action` 的分镜规范里**强制 2.39:1 电影画幅**——这是对的，它保住了质感。
但 2.39:1 是**极宽的横画幅**，直接发竖屏平台会出现两个结果：要么上下留大黑边，要么被裁掉两侧。

**三种适配方案，按场景选：**

| 方案 | 做法 | 优点 | 代价 | 什么时候用 |
|---|---|---|---|---|
| **A. 重构图出竖版** ⭐ | 用同一条提示词，把画幅改成 9:16 重新生成；用 base 二的「匹配剪辑」把横竖两版剪在一起 | 竖屏满屏、无损失 | 要多抽一轮 | **主力投放竖屏平台时选它** |
| **B. 补边** | 上下补模糊放大的同画面 / 纯色 / 渐变 | 一次生成，零重抽 | 上下是"填充感"，质感打折 | 只是同步发、不指望竖屏有量 |
| **C. 裁切** | 裁中间 16:9 或 9:16 区域 | 无额外成本 | **损失两侧构图，2.39:1 的横向调度全废** | 只在构图居中、主体够大时可用 |

**推荐策略：** 生成阶段坚持 2.39:1 保质感（横屏版发 B 站/官网），**另出一版 9:16 竖版专供抖音/小红书/视频号**。两版共用同一批参考图与首尾帧，一致性可控。**A 方案 + 只重出关键镜**（钩子、情绪高点、产品特写）是最省的做法。

## 四、安全区（最容易被 UI 裁掉的东西）

各平台播放页有固定的 UI 遮挡（底部文案/进度条、右侧点赞收藏、顶部信息栏）。**画面内容必须避开这些区域。**

- **通用做法**：关键信息（人脸、字幕、产品、Logo）放在画面**中央 60% 区域**，上下各留 **20% 安全边距**
- **抖音**：底部留出约 **200px** 安全区（放文案/挂车）
- **视频号**：**朋友圈分享时会被裁成 1:1** —— 核心信息必须放在**正中央**，否则转发出去就没了
- **小红书**：3:4 封面注意四角留白，标题区在图文笔记里独立
- **B 站**：横屏封面是 16:10，与 16:9 的视频**不同比例**，成品封面要单独做

> 落地到导演阶段的做法：分镜表里给**字幕预留位**。字幕是后期叠的，但如果主体占满画面，就没地方放字幕了。

## 五、导出参数（一次设对，省得反复）

| 参数 | 推荐值 | 说明 |
|---|---|---|
| 编码 | **H.264** | 兼容性最好；H.265 部分平台不接收 |
| 容器 | **MP4** | 所有平台通用 |
| 视频码率 | **16–20 Mbps**（1080p） | 平台会二压到 8–12 Mbps，**源文件给足** |
| 音频 | **AAC 320 kbps** | 音质与体积的最佳平衡 |
| 帧率 | **30fps**（动作类 60fps） | 通用选择 |
| 色彩空间 | **Rec.709 / sRGB** | 保证各设备显示一致 |
| 分辨率 | 1080×1920（竖）/ 1920×1080（横） | **别用 720p 上传**，压缩后会很糊 |

> 关键认知：**平台二次压缩是常态。** 你上传高码率源文件，压缩后还能看；你上传低码率，被再压一次就糊了。

## 六、封面与标题：必须在导演阶段就预留

封面不是后期随便截一帧。**它是信息流里的第一印象，也是转化的主要承载。**

- **封面素材在生成阶段就要单独准备**：挑一个"主体居中、表情/产品清晰、无文字"的镜，作为封面帧；不要用自动截帧的随机结果
- **封面文字密度要低**（尤其抖音）——满屏文字的封面在信息流里读不出来
- **小红书封面承担约 70% 的转化**：标题关键词要前置，可用 emoji
- **B 站封面单独做**（16:10），标题可容纳长尾关键词
- **平台标题 ≠ 分镜里的文案**：同一内容在不同平台要改标题、改封面，这是**不能被工具抹平**的一步

## 七、平台调性差异（决定同一素材怎么改）

| 平台 | 分发逻辑 | 对内容的具体要求 |
|---|---|---|
| 抖音 | **前 3 秒决定完播率** | 钩子必须最前；封面文字密度低；节奏快 |
| 小红书 | **封面承担大部分点击** | 3:4 封面；关键词前置；标题口语化 |
| 微信视频号 | **朋友圈转发是核心分发路径** | 文案要引导社交传播；1:1 中央安全区；画质给足（压缩狠） |
| B 站 | **搜索与长尾** | 标题可长、可带关键词；简介承担 SEO；横屏为主 |

> 因此：**"一稿通用"不如"一稿多改"。** 至少改标题和封面两项，这跟视频本身无关，但直接决定数据。

## 八、发布前检查清单

成片导出前逐项过：

- [ ] 画幅与目标平台匹配（9:16 / 3:4 / 16:9）
- [ ] 关键信息在中央 60% 安全区内，上下各留 20%
- [ ] 字幕/Logo 未被平台 UI 遮挡（尤其底部 200px）
- [ ] 视频号版本：核心信息在正中央（朋友圈会裁 1:1）
- [ ] 码率 ≥16Mbps、H.264、MP4、AAC 320kbps
- [ ] 封面单独准备（不是随机截帧），主体居中无文字堆叠
- [ ] B 站：封面按 16:10 单独做
- [ ] 标题按平台改过（不是直接把分镜文案粘上去）
- [ ] 平台侧合规自查已过（违禁词检测、画面尺度）

## 九、多平台分发节奏

同一素材全网同一时刻同步发，会触发两个问题：平台内部频率阈值、以及被算法识别为"跨平台搬运"。常规做法：

- 同一内容在不同平台**错开 30–120 分钟**
- 同一账号在同一平台的发布间隔 **≥2 小时**
- 重要内容**先发一个主平台**，2 小时后再分发

## 十、广告片专属发布要点

### 10.1 一稿两版：完整版 + 信息流版

品牌片几乎都要出两个版本，**在导演阶段就要预留**：

| 版本 | 时长 | 画幅 | 用途 | 注意 |
|---|---|---|---|---|
| **完整版** | 30s / 60s | 16:9 或 2.39:1 | 官网 / 发布会 / 大屏 / B 站 | 可以有完整情绪曲线，慢铺 |
| **信息流版** | 15s（甚至 6s） | 9:16 | 抖音 / 视频号 / 朋友圈广告 | **钩子必须最前**，无纯过渡镜 |

信息流版不是把完整版裁短，而是**按 15s 重新分镜**（见 `production.md` 六.6.5 镜数对照）。

### 10.2 结尾 Logo 定格的三个硬要求

结尾 Logo 是整个广告片的记忆点，容易被平台 UI 吃掉：

- **竖屏版**：Logo 定格必须落在中央 60% 区域内，避开底部约 200px 的文案/挂车区
- **视频号**：朋友圈转发会裁成 1:1，Logo 必须在**正中央**
- **停留 ≥2 秒**（SKILL.md 自检清单已有的那条）——生成时按 2 秒出，不要在后期压缩到 1 秒

### 10.3 品牌色在多平台的一致性

平台二次压缩会轻微改变色彩。保住品牌色的做法：

- 品牌主色**不要只靠细微色差**表达（压缩后可能看不出来）
- 关键画面里品牌色**占据足够面积的色块**，而不是小面积点缀
- 导出统一用 **Rec.709 / sRGB**，避免某些平台把广色域色彩映射得发灰

### 10.4 广告投放的合规与资质

- 投放平台的**广告审核比自然流量严格得多**：绝对化用语、效果承诺、对比贬损、数据出处都会被查
- 生成阶段就按 `compliance.md` 过一遍，**不要等投放被拒再返工**（返工要重抽、重新送审）
- 涉及特殊品类（医疗、化妆品、食品、金融）有额外资质要求，投放前先确认账号资质

### 10.5 广告片专属发布检查

- [ ] 信息流版（15s/9:16）与完整版（16:9）都已产出，不是裁短
- [ ] 竖屏版 Logo 定格在中央 60% 区域内
- [ ] 视频号版本 Logo 在正中央（防 1:1 裁切）
- [ ] 品牌色为大面积色块，压缩后仍可辨
- [ ] 投放平台广告审核项已自查（绝对化用语 / 效果承诺 / 资质）
