# 端到端示例：15s 高端腕表信息流 TVC

> 本文件走通一支广告片从 brief 到逐镜 prompt 的完整链路，作为 `ad-tvc` 的输出格式模板。
> 品类：高端机械腕表；渠道：抖音信息流（前 3 秒钩子 + 15s 快节奏）；调性：极简高级。

## 第 1 步：brief（6 项）

1. 品牌 / 产品：某独立制表品牌，自动机械腕表
2. 一句话卖点：**"时间拿它没办法"**（记忆点 = 材质耐久 + 时间意象）
3. 目标人群：30–45 岁男性，审美克制、反感炫耀
4. 情感调性：高级（克制、留白、材质冷光）
5. 时长与画幅：15s / 9:16 竖版
6. 投放渠道：信息流（前 3 秒必须有钩子）

> 假设项：人群与渠道按行业常规假设，已标注，待确认。

## 第 2 步：选导演人设

> 你是一位拍了 15 年高端消费品广告的导演。你信奉"克制比堆料更高级"——一条片子里只允许有一个视觉高潮，其余全部为它让路。你的工作顺序是：先定情绪落点，再找视觉母题，最后才分镜。

调性参数（查 `style-anchors.md`）：留白构图 + 固定机位/缓推 + 硬光侧逆勾边 + 低饱和中性色 + 单一金属冷调。

## 第 3 步：广告结构表（设计层，分镜前必出）

| 项 | 内容 |
|---|---|
| 核心卖点（唯一） | 时间拿它没办法（耐久 = 材质特写 + 时间意象） |
| 视觉母题 | 金属冷光在表壳上流动；结尾回到同色同光 |
| 钩子类型 | 反差：一枚表静静躺在风暴般的时间碎片里，纹丝不动 |
| 情绪落点 | 风暴散去，表静置在光里，人物松肩——"它不受影响" |
| 节奏骨架 | 15s / 6 镜 / 成片 1–2s；第 1 镜即钩子，第 5 镜为唯一视觉高潮（材质大特写），第 6 镜落点 |

## 第 4 步：分镜表

| 镜 | 戏剧/广告功能 | 时长 | 景别角度 | 运镜 | 画面内容 | 声音 |
|---|---|---|---|---|---|---|
| 1 | 钩子（反差） | 2s | 大特写 | 固定 | 表壳特写，背景是高速流动的时光粒子（光丝/尘屑）风暴般掠过，表纹丝不动 | 低频轰鸣 + 静默节点 |
| 2 | 展开（材质） | 2s | 微距 | 极缓推 | 金属冷光在表壳边缘流动，秒针反光一道划过 | 金属细微嗡鸣 |
| 3 | 展开（时间意象） | 2s | 中近景 | 固定 | 人物手腕入画，表在腕上，背景风暴渐缓 | 环境音渐入 |
| 4 | 转（反差回收） | 2s | 特写 | 固定 | 风暴停，一缕光落在表盘，指针静止 | 高频音骤停→静默 |
| 5 | 高潮（材质大特写） | 2s | 大特写 | 缓推+定格1帧 | 表盘全貌，金属冷光与蓝宝石镜面反光，品牌色一点冷蓝 | 一声清越钟鸣 |
| 6 | 落点 | 3s | 中景 | 缓拉 | 人物松肩，表静置光中；品牌色定格 ≥2s（后期叠加 Logo） | 渐弱至静默 |

## 第 5 步：逐镜提示词（可直接复制进视频模型）

```
镜1：一枚机械腕表表壳特写静置画面中央，背景高速流动的时光光丝与尘屑如风暴掠过、表身纹丝不动，
大特写，固定机位，硬光侧逆勾边，金属冷调低饱和、蓝宝石镜面一点冷蓝反光，
9:16 竖版电影画幅 / 2秒，低频轰鸣后一瞬静默

镜2：金属冷光沿表壳边缘缓缓流动、秒针反光一道划过，
微距，极缓推，硬光侧逆，低饱和中性色加冷蓝点缀，
9:16 / 2秒，金属细微嗡鸣

镜5（高潮）：机械腕表表盘全貌特写，金属冷光与蓝宝石镜面反光、一点品牌冷蓝，
大特写，缓推+定格1帧，硬光高对比，低饱和冷调，
9:16 / 2秒，一声清越钟鸣
```

## 第 6 步：自检

- [ ] 全片只围绕"时间拿它没办法"一个卖点
- [ ] 视觉母题（金属冷光）开头（镜2）与高潮（镜5）呼应
- [ ] 第 1 镜即钩子（反差：风暴中纹丝不动）
- [ ] 全片只有一个视觉高潮（镜5 材质大特写）
- [ ] 落点在画面状态（人物松肩、表静置光中），非 Logo 硬切
- [ ] 排除文字走构图，Logo 标注"后期叠加"
- [ ] 生成单元 4–10s / 成片 1–2s，余量给剪辑
