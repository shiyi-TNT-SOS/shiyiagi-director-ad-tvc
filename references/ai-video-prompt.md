# 分镜转视频模型提示词

> 视频模型（即梦 / 可灵 / Seedance / Grok / Sora）不吃分镜表，只吃单条 prompt。
> 本文说明怎么把分镜表的每一行，转成一条可直接粘贴的生成提示词。

---

## 拼装公式

```
[主体 + 动作] + [景别 + 角度] + [运镜] + [环境 + 光线] + [色彩 + 胶片] + [画幅 + 时长] + [排除项]
```

**顺序不能乱。** 视频模型对句首内容权重最高：

- 主体必须在最前 —— 决定画面里有什么
- 风格词放中间 —— 决定画面长什么样
- `8K / 超高清 / 电影感 / 大师作品` 这类词放句首 = 浪费预算，放中间或干脆不写
- 排除项放最后 —— 模型对句尾的否定词响应较好

---

## 转换示例

### 分镜表原始行

| 镜号 | 时长 | 景别 | 角度 | 运镜 | 画面内容 | 光影 | 色彩 |
|---|---|---|---|---|---|---|---|
| 3 | 5s | 特写 | 微俯 | 固定 | 一只手把精华液滴在手背并推开 | 窗边侧逆光 5600K | 暖白调 Fuji Eterna |

### 转成中文 prompt

```
特写，微俯角度，固定机位，一只手把精华液滴在手背上并推开，
窗边侧逆光 5600K，暖白调 Fuji Eterna，皮肤质感真实，
9:16，5秒，画面无叠加文字层，无慢动作，手指自然不变形
```

### 转成英文 prompt

```
Close-up, slightly high angle, static camera, a hand dropping serum onto the back
of the hand and spreading it, window side backlight 5600K, warm white tone,
Fuji Eterna film look, realistic skin texture, 9:16, 5s,
no slow motion, no deformed fingers
```

## 四条硬约束

### 1. 生成单元 4–10 秒（成片镜头 1–2 秒）

一条 prompt 产出的片段是"生成单元"，刻意留长（4–10 秒）给剪辑分段取用；剪完每个镜头的最终长度是 1–2 秒（短视频节奏）。超过 10 秒，当前主流模型的动作连贯性与主体一致性会明显下降。需要长镜头时，拆成 2 个短生成单元，后期拼接。

### 2. 避开高失败率内容

| 高风险 | 原因 | 替代方案 |
|---|---|---|
| 多人物交互 | 模型难以保持多人一致性 | 拆成单人镜头，或用过肩镜头遮挡一方 |
| 复杂手部动作 | 手指畸变是最高频失败点 | 改用手部局部特写，或让手部出画 |
| 快速运镜 | 甩镜、剧烈手持会崩坏 | 用缓推、环绕、固定 |
| 文字与 UI | 生成乱码 | 后期加字幕层，不要在 prompt 里要求文字 |
| 镜子反射 | 反射内容逻辑错误 | 避开或后期合成 |

### 3. 排除项（文字用构图，不用否定句）

模型会自作主张加水印、慢动作、畸变手指。但**字幕/文字不能写 "no text / 无字幕"**——
否定句会反被召唤出文字（negation summons）。正确做法：把画面描述为正向干净构图，
需要字幕时后期叠加字幕层。固定附加（除文字外）：

```
no watermark, no slow motion, no deformed hands, no extra fingers
```

中文：
```
画面无叠加文字层，无水印，无慢动作，手指自然不变形，无多余手指
```

> 文字一律走后期，prompt 里不出现 "text / 字幕 / 文字" 的否定式。

### 4. 主体一致性靠首尾帧

多镜头连续叙事时，用上一镜的最后一帧作为下一镜的首帧（图生视频），比纯文生视频的一致性高得多。这是当前最有效的多镜连贯方案。

## 各引擎参数差异

**完整能力矩阵、选引擎决策树、负面词的两种写法，统一见 `production.md` 第四章「引擎能力矩阵」**（含 2026-10 快照）。引擎事实只维护那一处，避免四处漂移。

本类型额外需要记住的：

- **入口 ≠ 模型**：即梦 = Seedance 入口，可灵 = Kling 入口。选型时问"哪一代模型"，不要问"哪个 App"。
- **中文 prompt 在即梦 / 可灵上效果更好**；Seedance 系对结构化提示词（主体 → 动作 → 镜头 → 光线）响应最好。
- **可灵有独立负面词字段**：实物类排除写进字段（`negativePrompt`），不写进正文。
- 需要**精确落首尾帧**时优先可灵；需要**单条 >15 秒**时只有 Seedance 2.5。

---

## 批量转换的输出格式

一次转多镜时，按这个格式给，方便逐条复制：

```
【镜 1】0-5s
中文：...
英文：...

【镜 2】5-9s
中文：...
英文：...
```

每条之间留空行，不要在 prompt 里带镜号（模型会把数字画进画面）。
