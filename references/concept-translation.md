# 调性词 → 视觉元件转译（广告片向）

> 用户常说"要高级感 / 治愈 / 很燃 / 科技感"。这类词**不能直接写进提示词**——模型不认识"高级感"，只会随机糊一个"看起来贵"的画面，或干脆忽略。
> 本文件把观感词展开成**模型能解析的视觉元件**：镜头 + 构图 + 运镜 + 光线 + 色彩 + 材质。规则与动作片 skill 的 `concept-translation.md` 同源。

## 核心规则

1. **观感词必须转译，禁止裸用进 prompt。** 写"高级感"进提示词 = 不合格输出。
2. **转译成六类元件**：镜头（景别/角度）+ 构图 + 运镜 + 光线 + 色彩 + 材质。缺哪类就补哪类，直到画面能被模型解析。
3. **判据**：这个词"在某一帧画面上看得到吗"——看得到才进 prompt；只在两镜相接才存在的（剪辑/轴线/节奏）只进分镜表（镜间 vs 镜内分流，见动作片 skill 同名文件）。

## 调性词转译表

| 用户说的 | 转译成视觉元件 |
|---|---|
| **高级感** | 留白构图（主体占 30–40%）；固定机位或缓推；硬光侧逆勾边；低饱和中性色 + 单一金属/石材冷调；材质特写（金属冷光/皮革纹理） |
| **治愈** | 自然光（晨光/窗边）；浅景深虚化背景；暖白调；缓慢微推；手部/表情特写；环境音保留（风声/水流） |
| **很燃** | 中近景 + 低角度仰拍，主体大；快切（单镜 1–2s）；甩镜点缀；硬光高对比逆光剪影；高饱和/青橙对比；强音效 + 冲击前静默 + 鼓点 |
| **科技感** | 深蓝冷底 + 单点亮色；环绕/升降运镜；UI/产品大特写；干净构图（对称/网格）；冷调硬光；电子音效 |
| **温暖** | 暖调侧光（夕照/烛光）；过肩镜头；浅景深；眼神与手部特写；柔光；环境暖噪 |
| **克制** | 单色调；大量留白；固定机位无运镜或极缓；单一材质特写；无装饰光；静默节点 |
| **国潮** | 材质微距（木/瓷/丝）；自然光；红金或青瓷配色；慢节奏长镜；传统意象放进现代场景 |
| **活力** | 手持跟拍或中速平移；高饱和；明快硬光；人物动作特写；轻快配乐与动作同步 |

## 禁词三类（写进 prompt 一律不合格）

| 类 | 例子 | 为什么禁 |
|---|---|---|
| **① 空泛无落点** | 史诗、震撼、极致、沉浸式、视觉盛宴、高级感（裸用）、大气、有质感 | 连"转译表"都无可落地的元件，纯占预算 |
| **② 镜间概念** | 快速剪辑、匹配剪辑、保持轴线、节奏调整、运镜流畅 | 属剪辑/调度，只进分镜表，单镜 prompt 写无效 |
| **③ 抽象结果** | 很高级、很有质感、很震撼、画面很美 | 是评价不是画面，模型无法据此生成 |

> "高级感"本身不是禁词——它是**触发词**，必须立刻按上表转译成六类元件，转完就把"高级感"二字丢掉。

## 否定词铁律（negation summons）

- 排除文字 / 字幕一律用**构图式排除**（"画面留白处无标识""品牌色由后期叠加"），**绝不写 `no text / 无字幕`**——否定句会反被召唤出文字。
- 实物类排除（水印 / 慢动作 / 手指畸变 / 塑料感皮肤）可正常写。
- Logo 与品牌色**始终由后期叠加**，不在 prompt 里要求生成文字。
