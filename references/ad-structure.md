# 广告结构 / 记忆点设计层（TVC 设计层）

> 本文件是 `shiyiagi-director-ad-tvc` 的"设计层"——对应动作片 skill 的 `fight-design.md`。动作片在写镜头前先想清楚"打什么"，广告片在写分镜前要先想清楚"这条片靠什么被记住"。
> **院线级广告和"一堆漂亮镜头拼在一起"的差距，八成来自这一步，不是镜头。** 镜头再美，没有结构和记忆点，观众看完只记得"好像挺好看的"。

## 零、为什么需要这一层

广告片最典型的失败不是"不好看"，是"记不住"：

| 失败 | 表现 | 本层的治法 |
|---|---|---|
| 漂亮但空洞 | 镜头都美，但没有一个被记住 | 先定**视觉母题**与**记忆点**，其余为它让路 |
| 卖点散 | 又想说功能又说情感又说促销 | **一个卖点原则**：全片只打一个记忆点 |
| 前 3 秒流失 | 信息流里观众划走了 | **钩子结构**：前 3 秒必须抛钩子或反差 |
| 情绪没落点 | 结尾硬切品牌 Logo | **情绪落点设计**：落点在人物/产品状态，不在 Logo |

**核心判断**：广告片的质量八成在"开拍前想清楚这条片靠什么被记住"。这一步决定"记不记得住"，镜头决定"好不好看"。跳过它，镜头再漂亮也是素材。

## 一、一个卖点原则

brief 里用户可能给了一堆想说的（功能、情感、促销、品牌）。设计层第一件事：**砍到一个**。

- 多卖点 = 没有卖点。观众记不住三个信息，能记住一个就不错。
- 选定后，全片所有镜头都要**服务这一个记忆点**，偏离的一律删。
- 记忆点不是"功能"，是"那一下"——一个动作、一个材质特写、一句反差台词、一个视觉符号。

> ✅ "这支表，时间拿它没办法"（记忆点 = 材质特写 + 时间意象）
> ❌ "我们的表精准、美观、有历史、性价比高"（四个卖点 = 没有卖点）

## 二、视觉母题（贯穿全片的记忆符号）

选一个**视觉元素**作为母题，开头埋、结尾回收，形成呼应。这是广告片最容易被 AI 忽略、却最值钱的结构手法。

| 母题类型 | 例子 | 用法 |
|---|---|---|
| 颜色 / 光 | 一束特定的光、一种品牌色 | 开头出现，结尾回到同色同光 |
| 道具 | 一杯水、一扇窗、一道门 | 开头特写建立，结尾同构图回收 |
| 重复动作 | 抬手、转身、低头 | 开头与结尾同一动作不同状态 |
| 材质 | 金属冷光、木纹、水波 | 全片材质统一，强化调性 |

> 例：开头人物总低头看手机（疏离），结尾手机静音扣桌上、抬头看人（连接）。AI 视频用同一构图前后呼应即可，不需要复杂调度。

## 三、钩子与结构（按渠道分两种）

### 信息流（抖音 / 朋友圈 / 信息流广告）——前 3 秒定生死

| 段 | 位置 | 任务 |
|---|---|---|
| **钩子** | 0–3s | 反差 / 提问 / 反常画面，逼停滑动。没有钩子 = 直接流失 |
| 展开 | 3–10s | 用 1–2 个镜头兑现钩子，带出产品 / 情绪 |
| 落点 | 最后 2–3s | 情绪或卖点落定 + 品牌色 / Logo 定格 ≥2s |

- 前 3 秒法则：要么抛反差（预期违背），要么给特写（材质 / 表情），要么问一句戳人的话。慢铺垫在信息流里必死。

### 电视 / 官网 / 品牌宣传片——可以慢铺陈

| 段 | 位置 | 任务 |
|---|---|---|
| 建置 | 0–30% | 氛围与调性铺陈，不急着亮产品 |
| 高潮 | 中点附近 | 视觉高潮（唯一允许的大场面 / 大特写） |
| 落点 | 结尾 | 情绪收束 + 品牌 |

- **一条片子只允许一个视觉高潮**，其余全部为它让路（极简高级派人设的工作顺序）。

## 四、情绪落点设计

全片情绪要有曲线，落点要明确：

1. 定基调（温暖 / 高级 / 科技 / 克制，只选一个，查 `style-anchors.md`）
2. 画情绪曲线：起 → 承 → 转 → 落。**落点必须在"释放后的平静"或"记忆点特写"**，不在最高点硬切。
3. 落点靠**画面状态**呈现（人物松开的肩、产品静置的光），不靠 Logo 硬切或字幕解释。

## 五、节奏骨架（镜数与时长分配）

| 片长 | 镜数 | 成片单镜 | 备注 |
|---|---|---|---|
| 15s 信息流 | 5–7 镜 | 1–2s | 前 3 秒必有钩子，节奏快 |
| 30s 完整版 | 8–12 镜 | 1.5–3s | 可有一处慢镜头作为情绪落点 |
| 品牌宣传片 | 10–15 镜 | 2–4s | 允许长镜头铺陈，但单镜生成仍 4–10s |

> **生成单元 ≠ 成片镜长**：生成单元 4–10 秒（一条 prompt 产出片段，给剪辑留余量），成片镜头 1–2 秒（短视频节奏）。与动作片 skill 的 `fight-design.md` 第九节同款口径。

## 六、输出：广告结构表（分镜前必出）

| 项 | 内容 |
|---|---|
| 核心卖点（唯一） | 这一支只打哪一个记忆点 |
| 视觉母题 | 哪个元素贯穿全片、何时埋 / 收 |
| 钩子类型 | 信息流反差 / 特写 / 提问（选一） |
| 情绪落点 | 落点在哪、靠什么画面状态呈现 |
| 节奏骨架 | 片长 / 镜数 / 单镜时长 / 高潮位置 |

**这张表在分镜表之前。** 它没填完，就不要写分镜——否则就是"一堆漂亮镜头拼在一起"。

## 自检（设计层交付前）

- [ ] 全片只围绕**一个**核心卖点，无第二卖点抢戏
- [ ] 视觉母题已定，开头与结尾有呼应
- [ ] （信息流）前 3 秒有钩子 / 反差 / 特写，不是慢铺垫
- [ ] 情绪落点明确，落在画面状态而非 Logo 硬切
- [ ] 全片只有一个视觉高潮（极简高级派原则）
- [ ] 节奏骨架与片长匹配（15s 不超 7 镜）
- [ ] 广告结构表已出，在分镜表之前
