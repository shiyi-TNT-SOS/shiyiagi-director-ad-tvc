# 风格参考坐标：把"我要那种感觉"翻译成可执行参数

> 用户说"高级感""治愈""很燃""有质感"时，这些词**不能写进提示词**（它们落不到画面上）。
> 但用户说的确实是有效的创作意图。这份文件做的事是：**意图 → 视觉特征 → 具体参数**。

---

## 一、为什么需要中间这一层

```
用户的语言          本文件的活              分镜表的语言
"要那种高级感"  →  调性 → 视觉特征 → 参数  →  85mm f/1.8 / 侧逆光 / 单色分区 / 静默
```

跳过去直接写"高级感"的后果：
- 模型把它当形容词，忽略或随机化
- 不同的镜头对"高级感"理解不一致，成片调性散掉
- 出了好片也不知道好在哪，无法复现

**中间这一层就是把模糊意图固化成可复用、可复现的参数组合。**

---

## 二、五轴映射法（把任何调性拆成 5 轴）

任何一个调性词，都能拆成下面 5 轴上的具体取值。**拆不出 5 轴 = 这个词太虚，先跟用户确认他要的到底是什么。**

| 轴 | 取值范围 | 常见错误 |
|---|---|---|
| **① 构图与景别** | 主体占画面比、留白比例、信息密度、视线朝向 | 只写"好看的构图" |
| **② 运镜与节奏** | 固定 / 缓推 / 环绕 / 手持；平均镜长；切点位置 | 一镜写多个运镜 |
| **③ 光线** | 方向（顺/侧/侧逆/顶/底）、硬度、光比、时段 | 只写"光线很美" |
| **④ 色彩与材质** | 主色调关系、饱和度、胶片模拟、材质质感 | 只写"色调高级" |
| **⑤ 声音** | 主体音效 / 环境音 / 静默节点 / 有无配乐 | 只写"配点音乐" |

> 与 `lens-grammar.md` 的七维的区别：**七维是"每个镜头必须填什么"，五轴是"调性怎么决定那七维填什么"。**
> 七维是填空题，五轴是判分标准。

## 三、调性反查表（用户口头语 → 坐标）

用户说的话往往不是他真正要的。**先翻译意图，再落参数。**

| 用户说 | 真正要的是 | ①构图 | ②运镜节奏 | ③光线 | ④色彩材质 | ⑤声音 |
|---|---|---|---|---|---|---|
| **"高级感"** | 克制、稀缺、不解释 | 大留白（≥50% 空），主体占比小 | 固定或极缓推；镜长 ≥3s | 硬朗侧逆光勾边，光比大 | 低饱和单色系，1 种主材质 | 静默为主，几乎无配乐 |
| **"有质感"** | 材质可触摸 | 特写 / 大特写，主体占满 | 固定 | 侧逆光，光比 1:4 以上 | 胶片模拟（Eterna / 250D），高细节 | 材质拟音（布料/金属/纸张） |
| **"干净"** | 信息少、秩序感 | 大留白 + 少元素，对称或三分 | 固定 | 均匀柔光，光比 ≈1:1 | 白 / 浅灰 / 单色，高调 | 单一环境音，无配乐 |
| **"治愈"** | 安全、暖、慢 | 中景为主，人物居中 | 缓推 / 固定；镜长 4–6s | 暖侧光 3200–4000K，柔 | 暖白调，低对比，低饱和 | 自然环境音 + 静默，轻柔配乐可 |
| **"很燃"** | 冲击、加速 | 中近景 + 低角度仰拍，主体大 | 快切；单镜 1–2s；甩镜点缀 | 硬光高对比，逆光剪影 | 高饱和 / 青橙对比 | 强音效 + 冲击前静默 + 鼓点 |
| **"大片感"** | 体量、纵深 | 大远景开场 → 人物远景（比重悬殊） | 缓推 / 升降 / 环绕 | 黄金时刻或冷调大光比 | 电影胶片模拟，青橙或冷暖分区 | 低频环境音 + 空间回响 |
| **"文艺"** | 疏离、留白、不解释 | 大留白，人物偏置，背对镜头 | 固定 / 极缓；镜长 ≥5s | 自然光，柔和侧光 | 低饱和，冷灰绿 | 环境音为主，无配乐 |
| **"真实"** | 不摆拍 | 中远景为主，构图不完美 | 手持轻微晃动 / 跟拍 | 自然光，不打光 | 无明显调色，颗粒 | 现场收音，保留杂音 |
| **"未来科技"** | 秩序、体量、精准 | 大留白 + 强对称，几何线条 | 环绕 / 升降；剪辑对鼓点 | 冷光 + 单点亮色源 | 深蓝冷底 + 单点亮色 | 电子音效 + 低频 |
| **"国潮"** | 东方审美进现代场景 | 材质微距 + 器物居中 | 慢节奏，缓推 | 自然光，柔和 | 红金 / 青瓷，低饱和 | 传统乐器点缀 + 环境音 |

**要避开的（反向坐标）**：

| 想避免的感觉 | 通常是这几项做错了 |
|---|---|
| 廉价 / 广告感重 | 高饱和 + 元素堆叠 + 影棚平光 + 满屏配乐 |
| 假 / 摆拍感 | 完美对称 + 影棚打光 + 过精致的动作 |
| 土 | "很燃"的节奏配了高饱和堆叠元素（燃的元素对了，色彩错了） |
| 空 / 记不住 | 全片平均用力，没有唯一视觉高潮 |
| 拖沓 | 镜长过平均值 + 在动作完成后才切 |

## 四、落地三步

1. **认调性**：从用户的话里认出**一个**（不是一个）核心调性词——"又高级又燃"不存在，让用户选一个
2. **查坐标**：查第三节拿到 5 轴的初步取值
3. **落到分镜表**：把 5 轴取值填进七维，逐镜保持一致；**同一支片子里 5 轴取值不能中途变**

> 判据：如果分镜表第 5 镜的光线/色彩跟第 1 镜取值不同，调性就断了——这就是"调性散掉"的技术定义。

---

## 五、两条铁律

- **调性词不进提示词正文。** "高级感""治愈""很燃"只用来查表，写进 prompt 的是查出来的参数。
- **调性决定的是"取舍"，不是"加法"。** 比如"高级感"的核心是**限制**（一种材质、一个高潮、大留白），不是加更多元素。**加元素永远拍不出高级感。**

## 六、8 个导演人设的完整坐标

`director-personas.md` 给的是**流派 + 信条 + 工作顺序**（"怎么想"）。这里是同一批人设的**参数坐标**（"怎么拍"）——选定人设后，直接查这张表填分镜。

### 1. 极简高级派

| 轴 | 取值 |
|---|---|
| 视觉特征 | 大留白、单一材质、单色分区、无多余元素 |
| ① 构图 | 主体占比 ≤1/3，留白 ≥50%，几何居中或三分 |
| ② 运镜节奏 | 固定 / 极缓推；镜长 ≥3s；全片**只允许一个视觉高潮** |
| ③ 光线 | 硬朗侧逆光勾边，光比 1:4 以上，窗边自然光 |
| ④ 色彩材质 | 冷暖单色分区，低饱和，Fuji Eterna；只出现 1 种主材质 |
| ⑤ 声音 | 静默为主，单一材质拟音，几乎无配乐 |

> 核心是**限制**而非加法：一种材质、一个高潮、大留白。

### 2. 温情叙事派

| 轴 | 取值 |
|---|---|
| 视觉特征 | 眼神与手部特写、过肩镜头、浅景深虚化背景、暖侧光 |
| ① 构图 | 中近景为主，过肩双人，浅景深（f/1.8–f/2.8） |
| ② 运镜节奏 | 缓推 / 固定；**切点给听者的反应**而不是说话人 |
| ③ 光线 | 暖侧光 3200–4000K，柔，光比小 |
| ④ 色彩材质 | 暖白调，低对比，柔和肤色（Fuji Eterna） |
| ⑤ 声音 | 环境音 + 静默；台词短、有潜台词；无背景配乐 |

> 禁用：快切、炫技运镜、直白的产品功能陈述。

### 3. 科技未来派

| 轴 | 取值 |
|---|---|
| 视觉特征 | 深蓝冷底 + 单点亮色、大体量、强对称、UI 大特写 |
| ① 构图 | 强对称，几何线条，大留白，主体带体量对比 |
| ② 运镜节奏 | 环绕 / 升降 / 缓推；剪辑**对鼓点** |
| ③ 光线 | 冷光 + 单一亮色光源，光比大 |
| ④ 色彩材质 | 深蓝冷底 + 单点亮色（通常是品牌色）；金属/玻璃质感 |
| ⑤ 声音 | 电子音效 + 低频 + 明确节奏点 |

> 禁用：暖调怀旧、叠化转场、杂乱赛博元素堆砌。

### 4. 国潮质感派

| 轴 | 取值 |
|---|---|
| 视觉特征 | 材质微距、器物居中、传统意象放进现代场景、自然光 |
| ① 构图 | 器物居中或材质微距填满画面 |
| ② 运镜节奏 | 慢节奏缓推，允许较长镜（≥4s），不赶 |
| ③ 光线 | 自然光，柔和；**避免影棚感** |
| ④ 色彩材质 | 红金 / 青瓷，**低饱和**；强调材质纹理 |
| ⑤ 声音 | 传统乐器点缀 + 环境音 |

> 禁用：大红大金堆砌、古装 cosplay、水墨特效滥用。信条是"把东方审美放进现代生活场景"。

### 5. 街头真实派

| 轴 | 取值 |
|---|---|
| 视觉特征 | 手持跟拍、自然光、中远景、构图不完美 |
| ① 构图 | 中远景为主，人物不居中，允许环境杂乱 |
| ② 运镜节奏 | 手持轻微晃动 / 跟拍；切点随意 |
| ③ 光线 | 现场自然光，**不打光** |
| ④ 色彩材质 | 无明显调色，带颗粒 |
| ⑤ 声音 | 现场收声，**保留杂音** |

> 禁用：影棚感打光、完美对称构图、慢动作滥用。宁可糙，不要假。

### 6. 幽默反差派

| 轴 | 取值 |
|---|---|
| 视觉特征 | 预期违背、突然定格、跳切、夸张音效 |
| ① 构图 | 中近景为主，反应镜多 |
| ② 运镜节奏 | 固定 + 跳切；反转点必须在 **3 秒内**；镜长 ≤8s |
| ③ 光线 | 明亮均匀（**喜剧必须看清脸**） |
| ④ 色彩材质 | 正常饱和度偏高，**不用低饱和**（低饱和会压掉喜感） |
| ⑤ 声音 | 夸张音效 + 画外音吐槽 |

> 禁用：慢节奏铺垫、抒情配乐、超过 8 秒不切换。

### 7. 女性视角派

| 轴 | 取值 |
|---|---|
| 视觉特征 | 手部与细节特写、柔光侧逆、暖白调、产品与皮肤同框 |
| ① 构图 | 特写为主，手部与细节，产品与皮肤同框 |
| ② 运镜节奏 | 缓推 / 固定，慢 |
| ③ 光线 | 柔光侧逆，光比小，无硬阴影 |
| ④ 色彩材质 | 暖白调，低饱和，Fuji Eterna；质感细腻 |
| ⑤ 声音 | 材质拟音（开盖 / 按压 / 涂抹） |

> 禁用：冷硬打光、纯功能演示、男性凝视式构图。信条是"拍出使用的愉悦感，不是功能清单"。

### 8. 自然纪实派

| 轴 | 取值 |
|---|---|
| 视觉特征 | 黄金 / 蓝调时刻、大远景开场、微距特写收尾、环境音保留 |
| ① 构图 | **大远景 → 微距**，两级跳 |
| ② 运镜节奏 | 固定 / 缓推，跟随真实动作，不干预 |
| ③ 光线 | 黄金时刻（暖侧光长影）/ 蓝调时刻（冷调均匀光） |
| ④ 色彩材质 | 自然色，不过度调色 |
| ⑤ 声音 | 环境音保留（风声 / 水声 / 鸟鸣） |

> 禁用：影棚布光、过度调色、摆拍痕迹明显的动作。

### 组合人设时

`director-personas.md` 的规则在这里同样成立：**信条只能有一条，否则 AI 取平均值。**

组合时坐标取法：**主调性决定 5 轴取值，副调性只改 1–2 轴**。
例：极简高级派（主）+ 科技未来派 → 保留极简的留白与固定机位，只把④色彩换成深蓝冷底 + 单点亮色。
**不要五轴各取一半**，那会同时失去两种调性。
