# 行为冒烟示例（等级 2）· 精品咖啡品牌片

> 本文件是 `shiyiagi-director-ad-tvc` 的可执行测试：用一支 30s 精品咖啡品牌片（含 15s 信息流版），跑通「选人设 → 定广告结构 → 分镜表 → 逐镜提示词」全流程，证明本 skill 能落地而非空话。

## 0. 测试场景

品牌：山岚咖啡；卖点：一口回甘；人群：都市白领；调性：高级 / 克制；时长：30s（信息流 15s）；画幅：16:9 + 9:16。

## 1. 第 2 步 · 选人设 + 广告结构

- **人设**：拍了 15 年高端消费品广告的导演，信奉"克制比堆料更高级"，只允许一个视觉高潮。
- **广告结构表**：唯一卖点=回甘；视觉母题=水流；钩子=前 3 秒特写注水；情绪落点=平静满足；节奏=慢铺→高点→留白。

## 2. 分镜表（15s 信息流版，6 镜）

| 镜 | 画面 | 戏剧功能 | 时长 |
|---|---|---|---|
| 1 | 注水慢镜，水流旋入杯心 | 钩子 | 3s |
| 2 | 咖啡师手部特写，蒸汽升 | 建立质感 | 2s |
| 3 | 都市人仰头饮下，闭眼 | 产品登场 | 3s |
| 4 | 回甘瞬间，嘴角微扬 | 情绪高点 | 2s |
| 5 | 空杯留渍，暖光 | 释放 | 3s |
| 6 | Logo 定格 ≥2s | 记忆点 | 2s |

## 3. 逐镜提示词（七段顺序）

**镜 1（钩子）**
> [水流缓入杯心，旋成涡] + [特写·俯角] + [极慢推近] + [柔光顶侧，杯壁高光] + [暖褐金调] + [9:16·生成 5s] + [注水白噪，无配乐]

**镜 4（情绪高点）**
> [饮者闭眼，回甘微扬嘴角] + [近景·平视] + [固定] + [窗侧自然光，面部柔光] + [低饱和暖调] + [9:16·生成 4s] + [环境静默 1 帧]

## 4. 自检（关键项）

- [x] 人设有流派+信条+工作顺序
- [x] 全片一个核心卖点（回甘）
- [x] 结尾 Logo 定格 ≥2s
- [x] 无广告法违禁；排除文字用构图（杯壁无标）
- [x] 主体句首；生成单元 4–10s
- [x] 信息流版与完整版分开产出（非裁短）

## 5. 结论

产出结构表 + 6 镜分镜 + 2 条可直接复制提示词，自检通过。反向对照：若只写"唯美咖啡广告"，AI 会产出一堆漂亮空镜拼不出记忆点。
