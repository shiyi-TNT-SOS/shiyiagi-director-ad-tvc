# 广告合规红线

> **重要**：本文为常见高风险表述的速查清单，用于起草阶段自查。
> 《广告法》条款与平台规则会更新，且各平台执行口径不同。
> **发布前必须过一遍投放平台后台的违禁词检测，并以平台最新规则为最终依据。**

---

## 一、绝对化用语（最高频违规）

| 禁用 | 安全替代 |
|---|---|
| 最好、最佳、最优 | 我用下来最顺手的 / 我们测试中表现最好的 |
| 第一、No.1、排名第一 | 具体名次 + 数据来源 + 时间范围 |
| 顶级、极品、极致 | 具体到参数或体验描述 |
| 国家级、世界级、全球领先 | 有官方认定则写明认定机构，否则删除 |
| 唯一、独家 | 具体到"某时间段内某渠道" |
| 全网最低、史上最低 | 删除，或写明比价时间与范围 |

---

## 二、效果承诺（普通商品最易踩）

| 禁用 | 安全替代 |
|---|---|
| 根治、彻底解决 | 缓解 / 改善 |
| 100% 有效、绝对有效 | 具体场景下的具体效果描述 |
| 一次见效、立竿见影 | 使用中可感受到的变化 |
| 永久、终身不再 | 长期使用的维持效果 |
| 无副作用、零风险 | 删除（任何产品都不能这样表述） |
| 包退包换包治 | 写明具体售后政策条款 |

---

## 三、医疗与功效暗示（普通化妆品 / 日用品 / 食品禁用）

| 禁用 | 说明 |
|---|---|
| 消炎、杀菌、抗菌 | 属医疗用语，非医疗器械/药品禁用 |
| 治疗、疗效、治愈 | 同上 |
| 修复受损、再生、激活细胞 | 化妆品备案范围外的功效宣称 |
| 美白、祛斑、防晒（特定数值） | 属特殊化妆品，需特证备案 |
| 减肥、燃脂、排毒 | 保健食品需蓝帽子，普通食品禁用 |
| 降压、降糖、降血脂 | 属药品功效，绝对禁用 |

**判断原则**：不是"能不能说"，而是"有没有对应的资质与备案"。没有特证/蓝帽子/医疗器械注册证，就按普通商品写。

---

## 四、数据与使用依据

- 引用数据必须标明来源、统计口径、时间范围
- "销量 XX 万"需有可验证依据，不得估算后写成精确值
- 用户评价、使用前后对比图不得伪造或过度处理
- 对比竞品时不得指名道姓贬低

---

## 五、特殊品类附加限制

| 品类 | 附加限制 |
|---|---|
| 食品 | 不得涉及疾病预防治疗功能；不得宣称保健功能（无蓝帽子） |
| 化妆品 | 不得宣称医疗作用；功效宣称需与备案一致 |
| 医疗器械 | 需审查广告批准文件，不得超出注册证范围 |
| 教育培训 | 不得承诺升学、就业、考试通过 |
| 金融理财 | 不得承诺保本保息、不得展示预期收益率 |
| 房地产 | 不得承诺升值、投资回报、学区（未确定） |
| 母婴 / 婴幼儿食品 | 不得宣称替代母乳 |

---

## 六、画面层面也会违规

不只是文案，画面同样受审：

- 不得出现伪造的检测报告、证书、奖牌
- 不得使用未经授权的品牌 Logo、人物形象、音乐
- 使用前后对比不得过度修图造成误导
- 不得出现引导私下交易、站外引流的二维码或联系方式
- 人物形象需有肖像授权，AI 生成人物建议在平台标注

---

## 起草阶段自查顺序

1. 全片文案搜一遍绝对化用语 → 替换
2. 功效描述对照备案范围 → 收窄
3. 数据类表述查依据 → 补来源或删除
4. 特殊品类对照上表 → 逐项确认
5. 画面元素查授权 → 替换或删除
6. **投放前：过平台违禁词检测**（这一步不可替代）
